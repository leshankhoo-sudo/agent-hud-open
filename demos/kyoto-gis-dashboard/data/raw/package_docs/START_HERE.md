# 京都旅游 Dashboard 资料包

这是制作起始资料，不是已完成的 GIS 分析结果。2026-11-10 整理。

## 怎样给 Claude
1. 解压此包。先上传 CLAUDE_BUILD_PROMPT.md、DATA_GUIDE.md 和 data_inventory.json。
2. 再上传 data 文件夹中的 GeoJSON 和 sample_journeys.json。若聊天窗口不接受 GeoJSON，可上传为文本或让 Claude 提供项目中的放置路径，不要改坐标内容。
3. documents 中的 Excel 是资料备查，PDF 是路线票价展示表。
4. 先要求完成真实点位地图和筛选，再做分析。不要一次承诺全府路线已经算好。
5. Claude 的预览和文件限制需实际测试。若预览不能读取外部 API 或本地文件，让它输出完整网页项目并提供部署说明。

- 暂用京都府现有边界，不代表已确定最终范围；若改京都市，需要重新筛选数据和统计。
- 523 条景点相关记录、5479 条站点记录。点位来自已有筛选，未重新核实其现实运营情况。

- 路线尚未计算。walking_routes.geojson 是明确标注的空文件，不是缺失数据应自动补全的指示。
- 密度分析未完成，天气未连通，票价示范行程尚未匹配景点 ID。
- 本包不包含之前 Claude 项目的源代码，因此是新建或人工整合用的资料包。

## 推荐制作顺序
真实底图和边界 → 景点/站点 → 点击和筛选 → 天气 → 小范围道路检查与路线测试 → 分析结果接入 → 3D 展示（可选）。
