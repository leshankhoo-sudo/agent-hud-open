# Mint & Apricot：p5.js 版 MV

整条渲染流程：Node.js 用 **puppeteer-core** 启动无头 Chrome，在 **p5.js** 画布上逐帧绘制，再把 JPEG 帧直接管道输给 **ffmpeg**，和原曲合成出片。

```bash
npm i
cp /path/to/song.mp3 .
node render.js MintApricot_p5.mp4 --w 1920              # 渲染整片，1080p 约 2.5 分钟
node render.js --w 960 --stills 5.0,13.4,23.7           # 只导出几张单帧用于检查
```

- `sketch.js`：每一帧都只由时间 t 决定（`window.renderFrame(t)`）。拍点网格为 `T0=0.244s`、`BP=0.4594s`（约 130.6 BPM），所有动作都写在"第几拍"上。
- 歌词字幕：放一个 `lyrics.json`，格式为 `[{ "start": 1.2, "end": 3.4, "text": "……" }]`，会自动以站酷快乐体显示在画面底部。
